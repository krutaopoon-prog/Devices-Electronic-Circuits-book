# วิชาอุปกรณ์อิเล็กทรอนิกส์และวงจร 20127-2004 (ปวช.) ฉบับเรียงตามหนังสือเรียน

สื่อการสอนแบบเว็บ (static site) สำหรับ GitHub Pages แยกโฟลเดอร์ตามบทของหนังสือเรียน (`ch04/` = บทเรียนที่ 4)
เว็บเดิมที่เรียงตามแผนการสอนอยู่ที่ `../Devices-Electronic-Circuits-slides/` (w01–w03)

- `index.html` หน้าแรก
- `chNN/slides.html` สไลด์ (← → / Space, T = สารบัญ, F = เต็มจอ) มุมขวาบนบอกหน้าหนังสือ
- `chNN/quiz.html` แบบทดสอบก่อน/หลังเรียน = แบบทดสอบหลังเรียนท้ายบทในหนังสือ (ข้อความตามหนังสือ ไม่สลับข้อ)
- `chNN/exercises.html` แบบฝึกหัด (ตรวจทันที, พิมพ์ใบงาน A4) + ชุดเขียนตอบ + ใบบันทึกผลการวัด
- `chNN/answers.html` เฉลยสำหรับครู (ต้องใส่รหัสครู)
- `ch04/bjt.js` + `bjt.css` ภาพสัญลักษณ์ โครงสร้าง ตัวถัง กราฟ IC–VCE ช่วงการทำงาน การไบแอส และรูปการวัดด้วยมิเตอร์เข็ม (วาดใหม่ทั้งหมด) และตัวจำลองในสไลด์
- `ch04/lab.html` + `tlab.js` + `tlab.css` + `meters.js` แล็บวัดทรานซิสเตอร์เสมือน ต่อยอดจากแล็บมิเตอร์ของวิชางานไฟฟ้าฯ บทที่ 2
  มิเตอร์เข็มย่านโอห์ม สายดำเป็นบวกเหมือนเครื่องจริง · มิเตอร์ดิจิทัลมีย่านไดโอดและช่อง hFE
  7 ภารกิจเรียงตามหนังสือ (`lab.html?m=4` เปิดภารกิจที่ 4, `m=0` โหมดอิสระสุ่มทรานซิสเตอร์, `&embed=1` ใช้ฝังในสไลด์)

## แก้เฉลย / เปลี่ยนรหัสครู
1. แก้ `_private/answers-chNN.json`
2. รัน `node _private/encrypt-answers.mjs chNN "รหัสครู"` จากโฟลเดอร์นี้ (ต้องมี Node.js 18 ขึ้นไป)
3. อัปโหลด `chNN/answers.enc.js` และ `chNN/check-data.js` ใหม่

`_private/` และ `บทเรียน/` (รูปถ่ายหนังสือ มีลิขสิทธิ์) อยู่ใน `.gitignore` ห้ามอัปขึ้น GitHub
